# Data

Raw datasets, extracted audio and generated noisy audio are **not** committed to Git.

## Speech: Indonesian-ASR-11-Class-Dataset

- Source: https://huggingface.co/datasets/Atika88/Indonesian-ASR-11-Class-Dataset (CC BY 4.0, DOI 10.57967/hf/10345)
- Download: `python -m src.data_loader download-speech` (or `--categories <Name> ...` for a subset, `--no-audio` for metadata only)
- Location: `data/raw/indonesia_asr/`. Category tar shards are extracted here, so `audio_path` in the metadata resolves relative to this folder.
- The resolved commit hash is saved to `data/raw/indonesia_asr/DOWNLOAD_INFO.json`.
- Source of truth: `metadata/dataset_metadata_public.csv`. The `split` column (`train`/`val`/`test`) is speaker-disjoint and is never reshuffled.

## Noise: MS-SNSD

- Source: https://github.com/microsoft/MS-SNSD. Only the `noise_train/` and `noise_test/` folders are used, never the clean speech.
- Download: `python -m src.data_loader download-noise` (sparse git clone)
- Location: `data/raw/ms_snsd/`
- Licence (per the MS-SNSD README): the noise comes from Freesound (CC0) and DEMAND (CC BY-SA 3.0). Per-file source is not specified upstream.

## Manifests (`data/processed/manifests/`)

| File | Content |
|---|---|
| `speech_manifest_raw.csv` | Metadata projection: audio_path, transcript, speaker_id, official_split, duration_sec, sample_rate, is_synthetic |
| `speech_manifest.csv` | The raw manifest plus audit statistics, `quality_status` (valid/review/invalid), `audit_flags` (every automatic flag), `auto_review` (rule decision with measured values), `exclusion_reason` (only for files that are not valid), `eligible_primary` |
| `noise_manifest.csv` | noise_path, noise_category, duration_sec, sample_rate, quality_status, audit_flags, exclusion_reason, `content_md5` / `duplicate_of` (byte-identical files), provenance_note |
| `manual_review_decisions.csv` | Manual overrides of the audit: `manifest,id,decision,note` |
| `noise_speech_check.csv` | Valid noise files screened for speech with Wav2Vec2: transcript, letters per second, `speech_suspected` |
| `conditions_<split>[_pilot].csv` | Utterance-noise pairing per condition: noise file, offset, seed, target/achieved SNR, per-utterance output gain, clipping flags |
| `speech_audit_summary.json` | Duration/RMS distribution, status counts, auto-review counts, flags raised, exclusion reasons |

Large manifests are git-ignored and regenerated by the scripts. The pilot manifests and summaries are small enough to commit.
